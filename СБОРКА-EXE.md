# 📦 Подробно: как собрать .exe (установщик Джарвиса)

После сборки у тебя будет обычный установщик Windows — как у любой программы:
запустил → установил → ярлык на рабочем столе. Командная строка больше не нужна.

> Перед этим у тебя уже должны быть выполнены шаги из [ЗАПУСК.md](ЗАПУСК.md):
> установлен Node.js, скачан проект, выполнен `npm install`, и `npm start` запускается.

---

## Шаг 1. Открой командную строку в папке проекта

1. Открой папку проекта (например `C:\Jarvis`) в Проводнике.
2. Кликни в **адресную строку** сверху (там, где написан путь).
3. Сотри путь, напиши `cmd` и нажми **Enter**.
4. Откроется чёрное окно уже в нужной папке — в заголовке будет `C:\Jarvis`.

## Шаг 2. Включи «Режим разработчика» (важно, делается один раз)

Сборщику нужно право создавать символические ссылки, иначе будет ошибка
`Cannot create symbolic link`.

- **Windows 11:** Параметры → **Система** → **Для разработчиков** → включи **«Режим разработчика»**.
- **Windows 10:** Параметры → **Обновление и безопасность** → **Для разработчиков** → **«Режим разработчика»**.

> Альтернатива: не включать режим, а запустить командную строку **от имени
> администратора** (Пуск → напиши `cmd` → правый клик → «Запуск от имени
> администратора» → затем команда `cd C:\Jarvis`).

## Шаг 3. Запусти сборку

В командной строке выполни:

```
npm run dist
```

**Что будет происходить (это нормально, не пугайся):**

1. При первой сборке скачаются инструменты сборщика (~50–80 МБ с GitHub) —
   дальше они кешируются, повторные сборки быстрее.
2. Побегут строки `• electron-builder`, `• packaging`, `• building`, `• building block map`.
3. Весь процесс занимает **3–10 минут** в зависимости от компьютера.
4. В конце командная строка просто вернётся к приглашению `C:\Jarvis>` **без красных ошибок** — значит, всё получилось.

## Шаг 4. Забери готовый установщик

Открой в Проводнике папку **`C:\Jarvis\release`**. Там будет:

| Файл | Что это |
|---|---|
| **`Jarvis Setup 1.0.0.exe`** | 🎯 Сам установщик — то, что тебе нужно |
| `win-unpacked\` | Распакованная версия — можно запускать `Jarvis.exe` прямо оттуда, вообще без установки |
| `*.blockmap`, `*.yml` | Служебные файлы, игнорируй |

## Шаг 5. Установи Джарвиса

1. Запусти **`Jarvis Setup 1.0.0.exe`**.
2. Если появится синее окно «Система Windows защитила ваш компьютер» (SmartScreen) —
   нажми **«Подробнее» → «Выполнить в любом случае»**. Это нормально: установщик
   не подписан платным сертификатом разработчика, поэтому Windows его «не знает».
3. Выбери папку установки (можно оставить как есть) → **Установить**.
4. На рабочем столе появится ярлык **Jarvis** — запускай как обычную программу. 🎉

> 💡 Установщик можно скинуть другу — ему не нужны ни Node.js, ни исходники.
> Всё уже упаковано внутрь (поэтому файл весит ~100+ МБ).

---

## 🧳 Вариант без установщика: один переносной .exe

Если хочешь один файл, который просто запускается с флешки без установки:

```
npx electron-builder --win portable
```

В `release\` появится **`Jarvis 1.0.0.exe`** — переносная версия.
Запускается чуть медленнее (распаковывает себя при старте), но не требует установки.

---

## 🔁 Поменял код — как пересобрать?

Просто снова выполни `npm run dist`. Старые файлы в `release\` перезапишутся.
Чтобы поменять версию (например 1.1.0) — исправь поле `"version"` в `package.json`.

## ❗ Возможные ошибки при сборке

| Ошибка в консоли | Причина и решение |
|---|---|
| `Cannot create symbolic link` / `A required privilege is not held` | Не включён режим разработчика — см. Шаг 2 (или запусти cmd от администратора) |
| `Get ... github.com ... connection timed out` | Сборщик не смог скачать инструменты: проверь интернет, отключи VPN, повтори команду |
| Антивирус удалил файл / ругается на `nsis` | Ложное срабатывание на упаковщик установщиков. Добавь папку `C:\Jarvis` в исключения антивируса и собери заново |
| `'electron-builder' is not recognized` | Не выполнен `npm install` в этой папке — вернись к Шагу 3 из ЗАПУСК.md |
| `EPERM: operation not permitted` при упаковке | Закрой запущенного Джарвиса и папку `release` в Проводнике, повтори сборку |
| Сборка «зависла» на `downloading winCodeSign` | Качает инструменты с GitHub — подожди пару минут; если совсем висит, прерви (Ctrl+C) и запусти снова |
