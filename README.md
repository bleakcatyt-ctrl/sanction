# 🤖 J.A.R.V.I.S — быстрые действия для ПК

Голосовой ассистент для Windows в стиле Джарвиса из «Железного человека»:
говоришь **«Джарвис»** — и отдаёшь команду. Или печатаешь её с клавиатуры.

| Категория | Примеры команд |
|---|---|
| 🚀 Запуск | `открой ютуб`, `открой блокнот`, `открой загрузки`, `открой стим`, `открой сайт vk.com` |
| 💻 Система | `выключи компьютер`, `перезагрузи`, `спящий режим`, `заблокируй`, `отмена выключения`, `очисти корзину`, `закрой хром` |

| ⛅ Погода | `погода`, `погода в Москве` |

## 🎤 Голосовое управление

- Распознавание речи работает **офлайн** (Vosk). Русская модель (~40 МБ)
  скачивается автоматически при первом запуске — дальше интернет для голоса не нужен.
- Активация: скажи **«Джарвис»**, дождись «Слушаю, сэр» и назови команду.
  Можно и одной фразой: «Джарвис, открой ютуб».
- Кнопка 🎤 — сразу режим прослушивания без слова-активации.
- Ответы озвучиваются голосом Windows (русские голоса «Ирина»/«Павел» есть в Windows 10/11).

## ⌨️ Горячие клавиши

- **Alt+J** — показать/скрыть окно из любого места системы.
- Крестик прячет приложение в **трей** — Джарвис продолжает работать в фоне.

## 🚀 Установка и запуск

📖 **Подробная пошаговая инструкция для новичков — в файле [ЗАПУСК.md](ЗАПУСК.md).**

Нужен [Node.js](https://nodejs.org) (LTS).

```bash
git clone https://github.com/bleakcatyt-ctrl/sanction.git
cd sanction
npm install
npm start
```



После сохранения просто говори: «Джарвис, открой фотошоп».

## 🗂 Структура проекта

```
main.js            — главный процесс Electron (окно, трей, Alt+J)
src/index.html     — интерфейс (HUD, реактор, чат, быстрые кнопки)
src/styles.css     — тёмная неоновая тема
src/renderer.js    — логика интерфейса и голосовой цикл
src/commands.js    — разбор и выполнение команд
src/stt.js         — офлайн-распознавание речи (Vosk WASM)
src/tts.js         — озвучка ответов (голоса Windows)
assets/icon.png    — иконка
```

## ❓ Частые вопросы

**Голос не работает.** Проверь, что микрофон подключён и разрешён в
Параметры → Конфиденциальность → Микрофон. Для первой загрузки модели нужен интернет.

**Джарвис не отвечает голосом.** Установи русский голос: Параметры → Время и язык →
Речь → Добавить голоса → Русский.

**Хочу другую клавишу вместо Alt+J.** Поменяй `'Alt+J'` в `main.js` (строка с `globalShortcut.register`).
