# 🚀 Подробная инструкция: как запустить Джарвиса на своём ПК (Windows)

Инструкция рассчитана на новичка — просто иди по шагам сверху вниз.
Всё займёт примерно 10–15 минут.

---

## Шаг 1. Установи Node.js

Node.js — это платформа, на которой работает приложение.

1. Открой сайт: **https://nodejs.org/ru**
2. Нажми большую зелёную кнопку **«Скачать Node.js (LTS)»** (LTS — стабильная версия).
3. Запусти скачанный файл `node-vXX.X.X-x64.msi`.
4. В установщике везде жми **Next** (ничего менять не нужно), в конце — **Install** и **Finish**.

**Проверка, что всё установилось:**

1. Нажми `Win + R`, введи `cmd`, нажми Enter — откроется чёрное окно (командная строка).
2. Введи команду и нажми Enter:
   ```
   node -v
   ```
   Должна появиться версия, например `v22.11.0`. Если появилась — всё отлично.

> ⚠️ Если пишет «"node" не является внутренней или внешней командой» —
> перезагрузи компьютер и попробуй ещё раз (после установки Node.js это иногда нужно).

---

## Шаг 2. Скачай проект

### Способ А — без Git (проще всего)

1. Открой страницу репозитория:
   **https://github.com/bleakcatyt-ctrl/sanction**
2. Переключи ветку: слева сверху нажми кнопку с названием ветки (`main`)
   и выбери **`arena/01a025ba-sanction`** — именно в ней лежит Джарвис.
3. Нажми зелёную кнопку **«Code» → «Download ZIP»**.
4. Распакуй архив, например, в `C:\Jarvis`
   (правый клик по архиву → «Извлечь всё…»).

### Способ Б — через Git (если он у тебя установлен)

Открой командную строку (`Win + R` → `cmd`) и выполни по очереди:

```bash
cd C:\
git clone https://github.com/bleakcatyt-ctrl/sanction.git Jarvis
cd Jarvis
git checkout arena/01a025ba-sanction
```

---

## Шаг 3. Установи зависимости проекта

1. Открой командную строку **в папке проекта**. Самый простой способ:
   - открой папку `C:\Jarvis` в Проводнике;
   - кликни в адресную строку сверху, сотри путь, напиши `cmd` и нажми Enter —
     командная строка откроется сразу в нужной папке.
2. Введи команду:
   ```
   npm install
   ```
3. Подожди 2–5 минут — скачается Electron и остальные пакеты (~300 МБ).
   Предупреждения жёлтым цветом (`npm warn`) — это нормально, не обращай внимания.

> ⚠️ Если появляется ошибка сети/TLS — проверь интернет, отключи VPN
> и попробуй снова. Иногда помогает команда `npm install` второй раз.

---

## Шаг 4. Запусти Джарвиса

В той же командной строке введи:

```
npm start
```

Откроется окно Джарвиса с «арк-реактором». 🎉

**Что произойдёт при первом запуске:**

1. Джарвис поздоровается в чате.
2. В статусе слева пойдёт загрузка **модели распознавания речи (~40 МБ)** —
   это один раз, дальше голос работает полностью офлайн.
3. Windows может спросить разрешение на **микрофон** — разреши.
4. Когда статус станет «Жду слово „Джарвис"» — всё готово.

**Попробуй:**

- Скажи: **«Джарвис»** → дождись «Слушаю, сэр» → скажи **«который час»**.
- Или одной фразой: **«Джарвис, открой ютуб»**.
- Или просто напиши в строке снизу: `помощь` — увидишь все команды.

**Полезно знать:**

- **Alt + J** — показать/скрыть окно из любой программы.
- Крестик ✕ не закрывает Джарвиса, а прячет его в **трей**
  (значок возле часов) — он продолжает слушать в фоне.
- Полностью закрыть: правый клик по значку в трее → **«Выход»**.

## Шаг 5 (по желанию). Сделай установщик .exe

📖 **Подробный гайд со всеми нюансами и решением ошибок — в файле [СБОРКА-EXE.md](СБОРКА-EXE.md).**

Коротко: чтобы запускать Джарвиса как обычную программу (ярлык на рабочем столе,
без командной строки):

1. В командной строке в папке проекта выполни:
   ```
   npm run dist
   ```
2. Подожди несколько минут. В папке `release\` появится файл вида
   **`Jarvis Setup 1.0.0.exe`**.
3. Запусти его и установи как обычную программу — на рабочем столе
   появится ярлык **Jarvis**.

## Шаг 6 (по желанию). Добавь свои программы и сайты

1. Скажи или напиши Джарвису: **«мои команды»** — откроется файл `commands.json`.
2. Впиши свои программы и сайты по образцу (обрати внимание на **двойные** `\\` в путях):
   ```json
   {
     "фотошоп": "C:\\Program Files\\Adobe\\Photoshop\\Photoshop.exe",
     "танки": "C:\\Games\\WorldOfTanks\\wot.exe",
     "мой сайт": "https://example.com"
   }
   ```
3. Сохрани файл (`Ctrl + S`). Теперь работает: **«Джарвис, открой фотошоп»**.

> 💡 Как узнать путь к программе: правый клик по её ярлыку →
> «Свойства» → поле «Объект» — скопируй его оттуда.

## ❓ Если что-то пошло не так

| Проблема | Решение |
|---|---|
| `node -v` не работает | Перезагрузи ПК после установки Node.js |
| `npm install` падает с ошибкой | Проверь интернет, отключи VPN/антивирус, повтори команду |
| Голос не распознаётся | Проверь микрофон: Параметры → Конфиденциальность и защита → Микрофон → разреши доступ приложениям. Для первой загрузки модели нужен интернет |
| Статус «Голос недоступен» | Микрофона нет или модель не скачалась — текстовые команды при этом работают полностью |
| Джарвис отвечает не по-русски / молчит | Установи русский голос: Параметры → Время и язык → Речь → «Добавить голоса» → Русский |
| Alt+J не срабатывает | Возможно, клавиша занята другой программой. Поменяй `'Alt+J'` на другую (например `'Ctrl+Shift+J'`) в файле `main.js` |
| Антивирус ругается при `npm run dist` | Это ложное срабатывание на упаковщик установщика — добавь папку проекта в исключения |
| Окно не открывается при `npm start` | Посмотри на ошибку в командной строке и проверь, что Шаг 3 (`npm install`) прошёл без ошибок |
